# BuildMeter for VS Code, Cursor and Antigravity

Measures how long you wait for a Flutter debug session (F5 / "Start Debugging") until the app is up on the device, and appends each record to `~/.buildmeter/events.jsonl`.

The records are shown by the BuildMeter macOS menu bar app and widget as daily, weekly and monthly summaries.
